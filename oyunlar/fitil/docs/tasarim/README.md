# Görsel yön önerileri (Ekim 2026)

Kullanıcı arayüzün "fazla yapay zekâ işi" durduğunu söyledi (ahşap + pirinç
perçin, parlak şekerleme taşlar, degrade düğmeler, kurdele başlıklar, Baloo).
İki yön için statik örnek ekranlar (oyun, bölüm kartı, kazandın; 390×844):

- `a-kibrit.html` — **Kibrit Kutusu**: eski kibrit etiketi / matbaa baskısı;
  dört mürekkep, düz renk, raster nokta gölge, kayık kalıp, Alfa Slab One +
  Archivo Narrow.
- `b-kagit.html` — **Kesme Kâğıt**: katmanlı mat kâğıt, origami katlı taşlar,
  yumuşak gölge, Young Serif + Atkinson Hyperlegible.

Yazı tipleri `node_modules/@fontsource/...` yolundan yüklenir (bu klasörde
`npm i @fontsource/alfa-slab-one @fontsource/archivo-narrow @fontsource/young-serif @fontsource/atkinson-hyperlegible`).
**Karar (19 Ekim 2026): ikisi de reddedildi.** Kullanıcı mevcut görsel dili
(gece kasabası, ahşap HUD, parlak kapsüller) ikisinden de güzel buldu. Yön
değiştirme önerme; iyileştirme gerekiyorsa mevcut dilin içinde, tek tek
öğelerde yap.
